# Emem Oloruntobi | Senior QA Engineer Portfolio

The personal portfolio of Emem Oloruntobi, a Senior QA Engineer with 6 years of experience testing payment, telecommunication and fintech systems. It covers my approach to quality, the tools I use, and the work behind each release.

## Sections
- **Achievements:** selected QA work across payments, POS, disputes and biometric KYC
- **Approach:** how I build quality into every step of a release
- **Toolbox:** automation, API, performance, test management and CI/CD tools
- **Experience:** expandable role cards showing experience
- **Contact:** email, LinkedIn, GitHub and resume

## Built with
Next.js, Typescript and CSS

## Run locally
1. Clone or download this repo.
2. Open the folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server**, or double-click the file.
